# NEXO Ingeniería — Sitio corporativo de demostración

**Concepto de web corporativa** diseñado como pieza de portafolio para **Sistemas JK**.

## Vista previa

**[Abrir la demostración en GitHub Pages](https://johankespinal.github.io/nexo-ingenieria-demo/)**

## Características
- Home corporativo de una sola página con hero visual, navegación anclada, presentación, servicios, proyectos de muestra y formulario.
- Diseño responsive para escritorio y móvil; menú móvil y resaltado de navegación.
- Formulario de contacto con validación local: **no envía ni almacena datos**.
- HTML, CSS y JavaScript sin framework ni backend; se puede publicar gratis en GitHub Pages.

## Abrir
Abre `index.html` en el navegador. Para publicar en GitHub Pages, configura *Settings → Pages → Deploy from a branch → main → /(root)*.

## Transparencia
**Nexo Ingeniería es una empresa ficticia.** Los proyectos, servicios y textos de la marca son conceptuales y no afirman trabajos reales, certificaciones, cifras ni testimonios. Las fotos se cargan desde Unsplash y requieren conexión; no son obras de Nexo ni del autor. Se utilizan con fines ilustrativos. El formulario no transmite información.

Un sitio comercial real necesita reemplazar datos y textos por información verificada, integrar un backend o proveedor de formularios, políticas de privacidad y, si corresponde, medidas de seguridad.
